Help - TrustVault

1. Account is not creating?

That username already exists. Try with a new username. Example: keerthi_owner1

2. Showing You are not an Owner / Viewer?

You must login with the same role you used while creating the account. A Viewer account cannot login as Owner.

3. How to upload?

Go to Owner Dashboard, enter Title, select File and click Upload.

4. Document not visible?

Type the Title in the Search box. If still not visible, contact Admin.
